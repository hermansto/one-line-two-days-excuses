One line, max 200 characters — the funniest AI excuse across two days.

> Day 1: I was going to finish the report. Day 2: I was still going to finish the report. Technically, the plan never changed.

`main.ts` writes that exact line (no trailing newline) to `entry.txt` in the output directory given by `MAKEFUN_OUTPUT_DIR`.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/two-days-excuses-out node main.ts
```
